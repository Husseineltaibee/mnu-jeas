# MNU-JEAS Journal Website

Static, responsive website concept for the Mansoura National University Journal of Engineering and Applied Sciences (MNU-JEAS).

## Contents
- `index.html` — single-page journal website with responsive navigation and sections for About, Aims & Scope, Guide for Authors, Peer Review, Publication Ethics, Volumes & Issues, and Repository.
- `assets/` — the three logos supplied for the journal, Faculty of Engineering, and university.

## Publish with GitHub Pages
1. Create a GitHub repository, preferably `mnu-jeas` or `mnu-jeas.github.io`.
2. Upload `index.html`, the `assets` folder, and this README to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish the site. A project site typically uses `https://YOUR-USERNAME.github.io/mnu-jeas/`. A user/org site uses `https://YOUR-USERNAME.github.io/` if the repository is named `YOUR-USERNAME.github.io`.

## Before public launch
- Confirm the final journal name and abbreviation. This site uses MNU-JEAS consistently.
- Confirm editorial policies, language policy, review model, revision deadlines, publication fees, copyright/license, and open-access terms with the university.
- Add the official submission system, editorial email, approved article template, volumes/issues, and repository links when available.
- Do not claim indexing, DOI registration, publication frequency, or live archive records until verified.
- The "Volumes & Issues" and "Repository" sections are launch-ready placeholders, not a live manuscript-management or article database.

## Suggested future management modules
1. Volumes & Issues: create/edit volume, issue, publication date, cover image, and article records.
2. Article repository: PDF/HTML, abstracts, keywords, DOI, author metadata, supplementary files, citation export.
3. Editorial dashboard: role-based Editor-in-Chief, editor, reviewer, and production permissions.
4. Submission workflow: submission intake, reviewer assignment, decision letters, revision rounds, production checklist.
5. Policy/CMS management: edit journal policies, announcements, templates, and contacts without changing source code.

This is a static front-end and does not include authentication, manuscript submission, peer-review workflow, or a database.
